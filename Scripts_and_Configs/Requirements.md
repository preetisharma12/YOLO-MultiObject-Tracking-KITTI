# Detection and Tracking Project Requirements

## Operating System
- Ubuntu 22.04 LTS

## Programming Language
- Python 3.10

## GPU
- NVIDIA GPU
- NVIDIA A100 GPU (used for training and evaluation)
- CUDA 12.x
- cuDNN (compatible with the installed CUDA version)

## Deep Learning Framework
- PyTorch
- TorchVision
- Ultralytics YOLO

## Object Detection
- Ultralytics YOLO
- Trained Models:
  - YOLOv8x
  - YOLOv10s
  - YOLOv10x
  - YOLO11s
  - YOLO11x
  - YOLO12s
  - YOLO12x
  - YOLO26s
  - YOLO26l
  - YOLO26x

## Multi-Object Tracking
- BoxMOT
- StrongSORT++
- DeepOCSORT

## Re-Identification
- Torchreid
- OSNet x0.25
- ONNX Runtime

## Evaluation
- TrackEval

## Python Libraries
- OpenCV (cv2)
- NumPy
- Pandas
- Matplotlib
- PyYAML
- tqdm
- SciPy

## Dataset
- KITTI Object Detection Dataset
- KITTI Tracking Dataset

## Trained Models
- YOLO detector models (.pt)
- KITTI-trained OSNet ReID model (.pth)
- KITTI-trained OSNet ONNX model (.onnx)

## Outputs
- YOLO detector weights
- StrongSORT++ tracking results
- DeepOCSORT-ReID tracking results
- TrackEval evaluation reports
